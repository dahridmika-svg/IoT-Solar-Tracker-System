# 🌞 IoT Solar Tracker System

## Overview

This project implements an IoT-based Solar Tracker using Arduino UNO and ESP32.

The system automatically detects the strongest light source using dual LDR sensors and rotates a servo motor to align a miniature solar panel accordingly. Real-time tracking information is transmitted to an ESP32 and displayed on a Wi-Fi web dashboard accessible through a smartphone or web browser.

## Features

- Automatic light tracking using dual LDR sensors
- Servo motor-based panel positioning
- ESP32 Wi-Fi web dashboard
- Real-time direction monitoring
- Live servo angle display
- Arduino UNO ↔ ESP32 serial communication

## Hardware Components

- Arduino UNO
- ESP32 Dev Module
- 2 × LDR Sensors
- Servo Motor (SG90)
- Mini Solar Panel
- Breadboard
- Jumper Wires

## Technologies

- Arduino IDE
- Embedded C/C++
- ESP32 Web Server
- IoT
- Serial Communication
